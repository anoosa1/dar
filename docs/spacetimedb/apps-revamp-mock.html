Apps revamp — Files, Contacts, Calendar, Notes, Tasks and the little things

Applies unified look B and settings sheet B more deeply inside every content app. The frame, rail, top bar and sheets stay exactly as selected; what changes is the content: one sheet header pattern (title or breadcrumb on the left, view controls on the right), a details sheet that leads with the object and a row of quick actions instead of stacked buttons, color that comes from the data (calendar and collection colors, file types, contact initials), and grouped, scannable lists. Menus get sections, correct icons and shortcut hints. Nothing here removes a capability: every existing action, permission rule, conflict state and keyboard path is still reachable.

Collection colors are drawn with SVG fill (as the collection dots already are) and file types/avatars use fixed class palettes, so the CSP stays style-src 'self' and there are no inline styles.

1 · Files — list with type tiles, breadcrumb title and the details sheet (light)

The breadcrumb is the title; Upload and the list/grid switch move into the header. Rows carry a tinted type tile, modified date, size and a shared marker. Details lead with a large tile, name and four quick actions; Rename/Move/Copy/Delete stay in the item menu as the guide requires.
