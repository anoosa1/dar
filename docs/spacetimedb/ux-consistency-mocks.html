One shared experience across Dar

Static design options informed by the supplied Nextcloud instance. All five apps keep the same launcher, account menu, New action, app-settings entry, menus, controls and overlay motion. Global settings keep separate Personal and Administration navigation. No production UI has changed.

These are visual mocks, not working controls. All variants have the same behavior. Creation actions use one shared component; app settings stay separate from global account/administration settings. Unsupported Nextcloud features are not implied by the mock.
