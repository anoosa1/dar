Common behavior

  • One right-hand pane for creating folders, files, contacts, calendars, events, tasks, address books, notebooks and task lists; existing full forms are reused.
  • Phones use a full-width pane with the same fields and sticky Save/Cancel actions. Focus returns to the initiating control. Unsaved changes are protected.
  • Files details retains metadata, Versions and Sharing. Rename, Move, Copy and Delete live in the three-dot menu. Pane geometry and scroll gutters stay stable across tabs.
  • Text and Markdown open in the Files editor. Formatting controls edit Markdown; Preview uses the existing safe renderer. Plain text remains plain text. Autosave/status, Ctrl/Cmd S, revision conflicts and recovery drafts are part of the editor.
  • Saving files creates ordinary retained file versions through the existing upload/version boundary. Read-only shares remain read-only; binary and oversized files retain download/preview.
  • Appearance applies to every app, menus, panes, settings and the editor. Light, Dark and Follow system persist per account. No extra dependencies are proposed.
  • Destructive confirmations and app-settings dialogs remain dialogs; creation and editing move to panes. Notes itself keeps its existing source/preview editor.

Static design reference; controls are illustrations, not a running application.
