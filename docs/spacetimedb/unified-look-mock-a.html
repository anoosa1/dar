A — The Agent frame, everywhere

Every app adopts the Agent's chrome exactly. The shared top header goes away: the 256px sidebar carries the app name and launcher at the top, a search row (Ctrl/Cmd+K opens cross-app search as a palette) and the account/settings footer. The center column has a quiet 48px heading, and creation/editing opens the focused right pane. Neutral surfaces, neutral selection; violet/rose accent is kept for primary actions, focus, today and live state. Twilight Afterglow/Nightfall tokens are unchanged.

A1 · Files — dark, file selected, upload drawer open

Places and collections are sidebar rows. The list is a compact 36px table in the center, and the selected file opens in the right pane. Transfers use the Agent's collapsible bottom drawer instead of toasts.

  • Sidebar 256px, soft surface, resizable; app name + Apps launcher at top, search row, nav rows, collapsible shelves at bottom, settings/avatar footer.
  • Rows are one 36px line: icon, title, right-aligned meta (count or age). Row actions replace the meta on hover/focus.
  • Selection is a neutral 9% text tint, not violet. Accent only for primary action, focus ring, live dot.
  • Center heading 48px: muted breadcrumb, 12px title, tool icons, one filled pill for the primary create action, pane toggle.
  • Right pane has a bordered 48px heading. Details use the Agent context card: bordered rows, 37px each.
  • Drawer: long-running work (uploads, imports, sync) uses a collapsible bottom drawer with tabs, like Agent output.
